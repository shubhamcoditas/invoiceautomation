# Assets Directory

This directory contains static assets for the application, including the default Emirates Airlines PDF.

## Default EA PDF

Place your default PDF file here with the exact filename:
**`2025-11-12_EK_176-212342123_Invoice_KAINMD55682 (1).pdf`**

The system will automatically serve this PDF whenever users search and click download in the Emirates Airlines module.

### Instructions

1. Copy your PDF file to this directory
2. Rename it to: `2025-11-12_EK_176-212342123_Invoice_KAINMD55682 (1).pdf`
3. Restart the server
4. The PDF will now be available for download

### Alternative Locations

If you prefer, you can also place the PDF in:
- `storage/pdfs/emirates/` directory
- `public/` directory
- Root directory of the project

The system will automatically find it in any of these locations.
